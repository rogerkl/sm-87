# SM-87's drum kit: the HR-16's sounds and its pads' set-up. The firmware has none of its own: a release package
# brings this one, as samples built in (the release workflow: tools/mkrom.py PACKAGE --kit resources/kit/kit.txt),
# which a package made again (mkrom.py, Axs7) replaces. The host simulator and the browser emulator have it built in
# (app/fm1.toml gen: tools/mkkit.py); run mkkit.py by hand to see what it holds and takes.
#
# It is the HR-16's own: its 16 drums each with the sound, level and pan an HR-16 sets it up with (V1.09, 153DH), the
# sounds from an Axs7 memory dump of them (its DRUMS bank, each START to END), the notes General MIDI's.
#
#   sound NAME FILE [vel=N]
#       a WAV file in this folder, mixed down to mono, at one of the sampler's rates (or resampled to the nearest),
#       12 bits as the sampler keeps it. NAME: up to 6 characters. vel: velocity's say in its level, 0..99 (the
#       sampler's VEL>LV; 60 unless told)
#   pad NAME SOUND [tune=N] [fine=N] [level=N] [pan=N] [note=N] [group=N] [poly=N]
#       the pads in order, up to 16 (the white keys from the lowest); SOUND a sound's NAME. tune: semitones
#       (-24..24), fine: sixteenths of a semitone more (-16..16, 0), level 0..99 (85), pan -3..3 (0), note: its MIDI
#       note (General MIDI's), group: pads that cut each other (the hats: 1), poly: its voices at once, 1 or 2 (the
#       HR-16's crash: 2; its ride has one)
#
# A pad saved keeps its sound by number: put new sounds at the end of the list (another kit built in: the pads saved
# with the last are its set-up again).
